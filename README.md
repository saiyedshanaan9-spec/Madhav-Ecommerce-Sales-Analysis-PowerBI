# Madhav Ecommerce Sales Dashboard

## Author
Shanaan

## Project Overview

This Power BI project provides an interactive dashboard for analyzing ecommerce sales performance. The dashboard helps track key business metrics such as revenue, profit, quantity sold, customer performance, payment methods, product categories, and state-wise sales distribution.

The goal of this project is to transform raw ecommerce transaction data into meaningful insights that support data-driven business decisions.

## Dashboard Features

### KPI Cards
- Total Sales Amount
- Total Profit
- Total Quantity Sold
- Average Order Value

### Sales Analysis
- State-wise Sales Performance
- Customer-wise Revenue Analysis
- Category and Sub-Category Analysis

### Profit Analysis
- Monthly Profit Trends
- Product Profitability Insights

### Customer Insights
- Top Customers
- Purchase Behavior Analysis

### Payment Analysis
- Payment Mode Distribution
- Transaction Trends

### Interactive Filters
- Quarter Filter
- State Filter

---

## Key Insights

- Identified top-performing states contributing the highest revenue.
- Analyzed monthly profit fluctuations to monitor business performance.
- Evaluated customer purchasing patterns and high-value customers.
- Compared product categories and sub-categories based on sales and profit.
- Assessed payment method preferences across transactions.
